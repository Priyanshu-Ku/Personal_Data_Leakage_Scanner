ExifTool setup for Windows

1. Download the Windows executable ZIP from https://exiftool.org/.
2. Extract the ZIP.
3. Rename exiftool(-k).exe to exiftool.exe.
4. Copy exiftool.exe and the complete exiftool_files folder into this tools folder.

Expected:
tools\exiftool.exe
tools\exiftool_files\...

The dashboard and command-line scanner use this local copy automatically.
